# Планирование спринтов — веб-приложение

Веб-приложение для планирования по двухнедельным спринтам: **добавление и редактирование** данных
(как в книге `Планирование_спринта_PRO.xlsx`) с автоматическим пересчётом метрик и диаграммами.

## Возможности

- **Редактируемые данные:** Бэклог, Команда, Релизы, Вехи, Технический долг, Риски, Баги, Параметры —
  добавление, изменение и удаление записей прямо в таблицах.
- **Автоматический пересчёт:** ёмкость и даты спринтов, план, velocity, % выполнения, загрузка,
  Time to Market, health-index, DRE, содержимое релизов, тренд техдолга, матрица рисков — обновляются
  при любом изменении.
- **Дашборд** с KPI (RAG-подсветка) и диаграммами (SVG, без внешних библиотек).
- **Автосохранение** в браузере (localStorage), **Импорт/Экспорт** данных в JSON, **Сброс** к исходным.
- Светлая/тёмная тема, адаптивный макет, работает офлайн (один файл `index.html`).

## Запуск

- Локально: открыть `index.html` в браузере.
- Онлайн (GitHub Pages): включить Pages для репозитория (Settings → Pages → Deploy from branch → `main` / root).
  Сайт будет доступен по адресу `https://neoandrey1985.github.io/Planirovanie/`.

## Модель данных и расчёты

- Даты спринта: `старт + (n−1)·14` … `+11`; рабочие дни — `ЧИСТРАБДНИ` (будни минус праздники из «Календаря»).
- Ёмкость спринта = Σ по команде `(раб.дни − отсутствия) × доступность × Focus factor`.
- План спринта = Σ оценок задач этого спринта; velocity = Σ оценок задач со статусом «Готово» (для закрытых спринтов).
- Time to Market = дата релиза − дата взятия задачи в работу; цель — 15 дней.
- Health-index = среднее из (% выполнения, готовность DoD, качество по открытым багам).

Данные приложения не покидают браузер (хранятся локально). Для переноса используйте Экспорт/Импорт JSON.
